# This game is currently under development

Controls:
- Crouch (C without sprint)
- Slide (C during sprint)
- Slide jump (C during sprint + Space)
- Wall run (Run on the big wall with no ledge attachments, jump from sideward angle to trigger)
- Weapon switch (Q, Overlay system is a bit buggy its the default from Yossi's)
- Prone (Hold C)
- Ledge (Jump to Attach)
- Ledge Climb/Drop (Space/Ctrl)
- Cover (F)
- Free Hang (Jump on a ledge with no Forward support)
- Hang Swing + Jump (WIP) (W and S (forward and backward) and Space for jump)

Running the Build:
- Extract the .exe from releases
- Open "EctopyBetaBuild.exe"
- Play!
